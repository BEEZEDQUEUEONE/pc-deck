One-click helper checking…

LibreHardwareMonitor is the standard sensor helper. It can be downloaded and started from here.

Windows asks for administrator permission when the helper starts — it needs that to read sensors. The dashboard itself never runs elevated.

Getting CPU temperatures ready
  1. Download the helper here, then press Start helper and approve the Windows prompt.
  2. In the helper window open Options → Remote Web Server → Run (port 8085).
  3. Press Test connection above. Package and per-core CPU temperatures, plus fan RPM, appear on the overview automatically.

Already running LibreHardwareMonitor or OpenHardwareMonitor? Just point the URL at it. Without a helper the dashboard still works — you get the GPU sensors that Windows and nvidia-smi expose.
